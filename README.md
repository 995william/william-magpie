# william-magpie

Magpie 坚果云跨电脑账号免登录自动同步插件 (支持 Windows & macOS 双向互通)。

解决多台电脑使用 Magpie 时，切换设备导致 Claude Code、Codex/ChatGPT 等订阅账号需要重复扫码授权的痛点。

---

## ✨ 核心特性

- **完全无感**：随 Magpie 启动自动常驻运行，无需手动执行脚本。
- **双向打通**：在电脑 A 登录，电脑 B 启动 Magpie 自动免登录。
- **Mac 专项适配**：自动注入 macOS Keychain 系统钥匙串，攻克 Mac 系统下 Claude Code 只认钥匙串的重复授权问题。
- **端到端加密**：本地采用 `AES-256-GCM + PBKDF2` 零知识加密，坚果云仅保存密文，保障账号安全。

---

## 🚀 安装方法（在 Magpie 客户端内）

在 Magpie 客户端的 **插件中心** 底部输入框中：

### 方式 1：通过 GitHub 仓库安装（推荐）
在输入框输入：
```text
github:995william/william-magpie
```
然后点击右侧的 **【安装】** 按钮。

### 方式 2：通过本地文件夹安装
在输入框输入本地路径：
```text
D:\DEV\my-project\william-magpie
```
或者点击输入框右侧的 **【📁 文件夹图标】**，选中该文件夹后点击 **【安装】**。

---

## ⚙️ 初次配置坚果云（只需一次）

在插件目录下双击运行 `setup.bat`（Mac 运行 `setup.sh`），按提示输入：
1. 坚果云账号（邮箱）
2. 坚果云应用密码（坚果云网页版：账户信息 → 安全设置 → 添加应用密码）
3. 自定义加密口令（多台电脑保持一致）
