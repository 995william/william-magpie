# william-magpie

Magpie 坚果云跨电脑免登录自动同步插件 (支持 Windows & macOS 双向互通)。

彻底解决多台电脑使用 Magpie 时，切换设备导致 Claude Code、Codex/ChatGPT 等订阅账号需要重复扫码授权的痛点。

---

## ✨ 核心特性

- **直接在 Magpie 内部拥有独立配置界面**：在 Magpie 侧边栏/插件中心中拥有专属 UI 页面。
- **自动复用坚果云配置（零手动输入）**：自动直接读取你在 Magpie 设置中已经配置好的坚果云地址、账号与应用密码，**完全无需重复手动输入**！
- **完全无感**：随 Magpie 启动自动常驻运行，无需手动执行脚本。
- **双向打通**：在电脑 A 登录，电脑 B 启动 Magpie 自动免登录。
- **Mac 专项适配**：自动注入 macOS Keychain 系统钥匙串，攻克 Mac 系统下 Claude Code 只认钥匙串的重复授权问题。
- **端到端加密**：本地采用 `AES-256-GCM + PBKDF2` 零知识加密，坚果云仅保存密文，保障账号绝对安全。

## 🚀 安装方法（在 Magpie 客户端内）

在 Magpie 客户端的 **插件中心** 底部输入框中：

### 方式 1：通过 GitHub 仓库安装（推荐）
在输入框输入：
```text
github:995william/william-magpie
```
然后点击右侧的 **【安装】** 按钮。

### 方式 2：通过本地文件夹安装
在输入框输入本地路径：
```text
D:\DEV\my-project\william-magpie
```
或者点击输入框右侧的 **【📁 文件夹图标】**，选中该文件夹后点击 **【安装】**。

---

## 💡 使用说明

安装完成后，直接在 Magpie 侧边栏点击 **【免登同步】** 打开插件面板：
1. **自动继承**：页面会自动显示已检测到的 Magpie 原生坚果云配置。
2. **免维护**：插件会在后台静默工作，无需手动操作。
